BanGar

Moderation and community bot for The Getaway Discord server

BanGar handles day-to-day moderation, keeps a full activity log for staff, and gives members leveling, polls, a starboard, and a few games to play.

  • 25commands
  • 10feature modules
  • !default prefix

Overview

BanGar is a single-server Discord bot written in asynchronous Python with discord.py 2.4. It stores its data in PostgreSQL and runs on Heroku as a worker process.

Moderation

Kick, ban, mute, and clean up channels, with automatic protection against mention spam.

  • Timed mutes that lift themselves
  • Bulk message deletion, filtered by member
  • Every action posted to the mod log

Logging

Message edits and deletions, plus name, nickname, avatar, and role changes.

Leveling

Members earn XP for chatting and climb a server leaderboard.

Starboard and polls

Starred messages get reposted. Moderators run native Discord polls.

Modmail

Members DM the bot to reach the moderators privately.

Getting started

Every command starts with the server's prefix, which is ! by default. You can also mention the bot instead of typing the prefix:

Discord
!help
@BanGar help

Run !help to see every command, or !help <command> to see how to use one. Moderators with the Manage Server permission can change the prefix with !prefix (up to 5 characters).

If you run a command while BanGar is starting up, it replies "Bot is still initializing." Wait a few seconds and try again.

Moderation

Moderation commands check both your permissions and BanGar's. BanGar can only act on members whose highest role is below its own, so keep its role near the top of the role list.

How mutes work

  • A mute removes the member's roles, gives them the Mute role, and saves their old roles in the database.
  • Unmuting, by command or when the timer runs out, restores the saved roles.
  • Leave out the minutes to mute until a moderator runs !unmute.
Example
!mute @Rowan 30 Spamming the trade channel
!clear @Rowan 50
!unmute @Rowan Appeal accepted

Logging

BanGar posts an embed to the mod log channel for each of these events:

EventWhat's recorded
Message editedThe author and the message before and after
Message deletedThe author and the deleted text or image
Profile changedUsername, display name, avatar, or discriminator, before and after
Roles changedThe member's roles before and after
Moderation actionKicks, bans, mutes, and unmutes, with the member and reason

Errors go to a separate bot-errors channel, so they don't clutter the mod log.

Modmail

Members can message the moderators privately by sending BanGar a direct message of at least 10 characters. BanGar forwards it to the mod log with the member's name and avatar, and replies "Message relayed to moderators."

Community features

Leveling

Members earn 10 to 20 XP for a message, once per minute, so spamming doesn't speed it up. Levels follow this curve:

level = floor(XP ÷ 42) 0.55

Level-ups are announced in the level-up channel. Check progress with !level, !rank, and !leaderboard.

Starboard

React to a message with ⭐ to send it to the starboard channel. Each new star updates the count on the starboard post. Stars on your own messages or on bot messages are removed.

Polls

Moderators create native Discord polls with up to 10 answers. The question goes first in quotes, then the duration in hours, then true or false for multiple choice, then the answers:

Example
!createpoll "Raid night?" 24 false Friday Saturday Sunday

Name colors and welcome messages

  • React with ❤️, 💙, or 💜 on the role-select message to pick a name color. Choosing a new color replaces the old one.
  • New members get a welcome message, a welcome DM, and a starting role. A goodbye message is posted when someone leaves.
  • Every Monday at 12:00, BanGar reminds the general channel to follow the rules.

Crit or Quit

!gamble hosts a gold-rolling game in the channel. Each round, everyone who joined rolls between 0 and the round's gold cap. The highest roll wins, and the lowest roller owes the winner the difference. The cap goes up by the increment every round, and BanGar posts a payout summary at the end.

Type in chatEffect
jr or 1Join this round
lr or 0Leave this round
js or 3Join every remaining round
ls or 2Leave the session

Up to 25 players can join a round, and a session can run up to 20 rounds. A round needs at least 2 players.

Self-hosting

BanGar is built for The Getaway, so its channel and role IDs are set in the code. To run it on another server, first replace those IDs (see Configuration).

  1. Create a bot in the Discord Developer Portal and turn on all three privileged gateway intents.
  2. Clone the repo and install the dependencies:
    bash
    git clone https://github.com/ChrisRaiz/BanGar.git
cd BanGar
pip install -r requirements.txt
  3. Set the two environment variables and start the bot:
    bash
    export DISCORD_BOT_TOKEN="your-bot-token"
export DATABASE_URL="postgresql://user:password@host:5432/dbname"
python3 launcher.py

BanGar creates its database tables the first time it starts.

Deploying to Heroku

  1. Create a Heroku app and add Heroku Postgres, which sets DATABASE_URL for you.
  2. Add DISCORD_BOT_TOKEN under Settings, then Config Vars.
  3. Push the repo and turn on the worker dyno. The Procfile runs python3 ./launcher.py on Python 3.12.
